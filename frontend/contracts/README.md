# Frontend contracts

- `index.ts`: TypeScript mirrors of the backend Pydantic models, plus API endpoint paths and response shapes.
- `schema/*.schema.json`: JSON Schemas generated from the Pydantic models (`python backend/scripts/export_contracts.py`). A backend test fails if they drift.

## Endpoints

| Path | Response |
| --- | --- |
| `GET /health` | `HealthResponse` |
| `GET /games?season=&week=&season_type=&limit=&offset=` | `GamesListResponse` |
| `GET /games/{game_id}` | `GameDetailResponse` |
| `GET /games/{game_id}/plays?limit=&offset=` | `PlaysResponse` |
| `GET /games/{game_id}/win-probability?swing_threshold=0.08` | `WinProbabilitySeries` |

## Win probability conventions

- **Perspective:** home team. `home_wp_pre` / `home_wp_post` = P(home team wins). `CanonicalPlay.reference.wp` is the *possession* team's WP (nflverse); don't chart it directly.
- **Timing:** `home_wp_pre` is before the snap. `home_wp_post` is the next play's pre-snap value; on the last play it is the final result (1 home win, 0 home loss, 0.5 tie).
- **Swing play:** `is_swing` when `|delta_home_wp| >= swing_threshold`. Default 0.08; per-request `?swing_threshold=`, server default `NFL_SIM_SWING_WP_THRESHOLD`. `swing_play_ids` lists them in order.
- **Overtime:** quarter 5, `is_overtime: true`, `has_overtime` on the series. `game_seconds_elapsed` keeps counting past 3600 (regular-season OT 600 s, postseason OT 900 s), so the x-axis never rewinds. A regular-season tie ends at 0.5.
- **Source:** nflverse/nflfastR published `home_wp` (`truth_label: "historical"`), not this project's model.

## Quiz pack (`frontend/lib/quizPack.json`, type `QuizReveal` in `frontend/lib/quiz.ts`)

`reveal.layman_why` and `reveal.assumptions` are display text in plain fan language (no "WP",
"edge ≈", "isotonic", "yardline_100"). The frontend pack carries no model details at all.
The backend copy (`backend/src/nfl_sim/quiz/data/curated_pack.json`) additionally keeps
`reveal.edge_wp` and `reveal.model_notes`; the generator strips them from the frontend export.
Generated by `backend/scripts/build_quiz_pack.py`.

## Real swing plays (`frontend/lib/swingPlays.json`, types `SwingGame` / `SwingPlay` in `frontend/lib/wpFixtures.ts`)

Built by `backend/scripts/build_swing_examples.py <pbp_2023.parquet>` from real nflverse rows (QA H5/M9).
CI (`backend/tests/test_swing_examples.py`) checks every play against a committed pbp slice
(`backend/tests/fixtures/swing_pbp_rows.json`) on game_id / play_id / qtr / clock / desc, and that the export rebuilds identically.

```
{ source, wp_source, swing_filter, top_n,
  games: { [game_id]: {
    game_id, home_team_id, away_team_id, home_score, away_score,   // final, incl. OT
    first_home_wp,                                                 // nflverse pre-snap home WP of the first row
    opening_home_wp, opening_away_wp,                              // nflverse pre-snap WP at the first real play (kickoff); away = 1 - home
    swings:         SwingPlay[],  // top_n by |delta_home_wp|, shared swing filter, in game order
    overtime_plays: SwingPlay[],  // OT scoring plays, NO win-chance fields (house rule)
    chart:          SwingPlay[]   // every regulation play row with WP (+ swing_eligible), for the line
} } }
SwingPlay = { game_id, play_id /* nflverse play_id as string */, qtr /* 5 = OT */, clock /* "MM:SS" quarter clock */,
  clock_seconds, description /* nflverse desc, verbatim */, play_type, possession_team_id,
  home_score_after, away_score_after, home_score_before, away_score_before,
  down, distance /* ydstogo */, yardline_100,   // null when nflverse has none (kickoffs, PATs)
  yards_gained /* nflverse yards_gained, null if none */,
  return_td /* interception or fumble returned for a TD (nflverse return_touchdown, or td_team != posteam) */,
  fourth_down_failed /* down == 4 && nflverse fourth_down_failed == 1 */,
  event /* turnover_on_downs | interception | fumble_lost | touchdown | field_goal | punt | other */,
  display_text /* fan text, <= 20 words: show this */,
  penalty_text /* string | null: flags after a play, shown after display_text; null on 'No play' rows */, raw_desc /* verbatim nflverse desc */,
  home_wp_pre?, home_wp_post?, delta_home_wp? /* swings */, swing_eligible? /* chart */ }
```

Full play lists: `frontend/lib/plays/<game_id>.json` = `{ game_id, plays: SwingPlay[] }` (type `GamePlayList`),
every real play in order incl. penalties/no-plays, kickoffs, PATs and OT; no timeouts, two-minute warnings or
quarter/game markers. Kept out of swingPlays.json for size (~85-92 KB each); fetch/import per page.

Game files (`/data/games/<game_id>.json`, game.v2, shipped in the `games-v3` release asset and later): `cols.display_text`
is one fan-facing sentence per row, same `play_text.display_text` as `lib/plays` (identical for the shared games),
plus `cols.penalty_text` (same rules as lib/plays); game-flow rows read "Start of game.", "End of quarter N.", "Two-minute warning.",
"Timeout by TEAM.". `expandGameV2` exposes it as `play.display_text` (falls back to raw `text` on games-v2 files);
`text` stays verbatim nflverse.

`penalty_text` (UI Critic P2-J/P3-H/P3-I): accepted "Penalty on Name (TEAM): foul, N yards against TEAM.";
declined "Flag on Name (TEAM) for foul, declined." or "Two NYJ flags declined: foul (Name) and foul (Name).";
all-offsetting "Offsetting penalties: foul on A (DET) and B (KC). The down is replayed." 'No play' rows keep the
flag in `display_text` ("Penalty on Name (TEAM): foul, N yards. No play.") and have `penalty_text: null`.

`display_text` rules (`backend/src/nfl_sim/play_text.py`): no clock, formation tags, jersey numbers, tackler
parentheses or pressure brackets; sentence case; full names from nflverse player ids (players.csv) for the main
roles, otherwise nflverse short names as written (e.g. kickoffs, kneels); <= 20 words; only facts in the row.
`event` priority: turnover_on_downs > interception > fumble_lost > touchdown > field_goal > punt > other.

Swing filter: regulation (qtr 1–4) `run` / `pass` / `field_goal` / `punt` only; kneels, spikes, no-plays, kickoffs,
timeouts and other non-play rows never swing. WP is nflverse's `home_wp` / `home_wp_post`, not our model.

Team colors: `frontend/lib/teamColors.json` = `{ _source, _tertiary_notes, teams: { [team_abbr]: { primary, secondary, tertiary } } }`,
the 32 current nflverse abbreviations the repo uses (Rams = `LA`; `LAR`/`OAK`/`SD`/`STL` alias rows dropped), uppercase
`#RRGGBB` from nflverse `teams_colors_logos`: `primary` = `team_color`, `secondary` = `team_color2`, `tertiary` =
`team_color3`. When color3 is missing, neutral (white/black/gray) or an exact duplicate of primary/secondary, `tertiary`
is `team_color4` if that is a distinct non-neutral color (not within RGB distance 40 of primary/secondary); otherwise
nflverse's color3 is kept (or color2 when color3 and color4 are both blank: NYJ, TEN). Every such team is listed with
the reason in `_tertiary_notes`. No colors are invented and there is no neutral fallback. Colors only, no logos.
Regenerate with `python backend/scripts/build_team_colors.py`; checked by `frontend/lib/teamColors.test.ts`.

Team logos: self-hosted under `frontend/public/teams/<ABBR>/logo.png` and `wordmark.png` for the same 32 abbreviations
(never hotlink at runtime). `frontend/public/teams/manifest.json` (copy: `frontend/contracts/teamLogos.json`, types:
`frontend/contracts/teamLogos.ts`) = `{ _source, fetched, teams: { [team_abbr]: { logo, wordmark } } }`, each file
`{ path, source_url, bytes }` with `path` site-relative (`/teams/KC/logo.png`). Logos come from nflverse
`team_logo_espn` (ESPN), shrunk to 256x256; wordmarks from nflverse `team_wordmark`, capped at 600px wide; both are
256-colour palette PNGs with alpha. Regenerate with `python backend/scripts/fetch_team_logos.py` (needs network and
Pillow); checked by `frontend/lib/teamLogos.test.ts`.
